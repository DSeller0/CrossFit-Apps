me.html · PR board as sub-cards

#55 / #87 · plans/38 Phase B (Lane B ideation). Redesigns me.html's PR board from a two-level disclosure list (block accordion → exercise rows → detail row — you can't see a single PR value without two taps) into family cards holding a grid of PR tiles, so best values are glanceable. Reuses the real primitives: blkColor family colors (data — same in every theme), TallyBar (10-block, data-color fill), prBest/prPct/prDelta. me.html is a public page → square corners (no border-radius except the circular family dot), per the design-system rule.
#87 benchmarks: named WODs are currently in PR_SKIP (it holds all WOD_TYPES, and Benchmark is one). A benchmark's PR is its completion time — a type:'time' PR, a different surface from per-movement load/reps. It gets its own card below the movement families; the other WOD-score types (For Time / AMRAP / EMOM / MetCon / HIIT) stay skipped. One AMRAP benchmark (Cindy) shows the rounds-PR variant the same tile absorbs. Not built — this stops at the approval gate; build lands in PrSection.jsx + Me.module.css after sign-off.
