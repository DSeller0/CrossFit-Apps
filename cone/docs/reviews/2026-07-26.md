## High

**U1 · The SPA topbar eats 27% of a phone screen and overflows horizontally.**
Measured live at 390×844, Exercícios tab: `.topbar` is **226px tall** because its five state
buttons (Sair · Sincronizar · Limpar estado · Carregar estado · Salvar estado) stack
vertically at `x=199`, `y=33→215`. `document.scrollWidth` 387 > `clientWidth` — the page
scrolls sideways, and the account email is visibly clipped. This is SPA **chrome**, so it
costs every tab on mobile, not just this one. Not attributable to C1; it predates it and no
C-session owns the topbar. → **#95**

**U2 · Exercícios at 1280 gives the most space to the emptiest pane.**
Measured: sidebar 220 + Pane 1 224 + Pane 2 **340** = 784px, leaving **~496px (39% of the
window)** for the Pane-3 detail, which on load holds one line of italic placeholder. Pane 2
is the card grid — the densest content on the page — and at 340px it renders 2 narrow cards
per row behind its own inner scrollbar. The proportions are inverted with respect to content
density. Same family as #18 (index's dead right half), on a tab that just shipped. → **#96**

**D1 · TV's timer ring colour ramp is still frozen to the dark palette.**
`tv/slides.jsx:38-40` `'#48b860'`/`'#d8a840'`/`'#c84038'` (the remaining-time green→amber→red
ramp), `:227` `'#4878d8'` (the resting ring) and `TV.module.css:141` `background:#c84038`
paired with `color: var(--cream)` on the same declaration. #85 fixed the ring **track**; the
ramp it draws over was not in that row's scope. Public-facing, on the gym wall, wrong in both
light themes. Note `TV.module.css:14` `background:#000` is the deliberate blank-slide rule —
leave it. → **#97**

**A1 · Four public pages still render with no landmark and no heading.**
Measured live, not grepped: `index`, `timer`, `tv`, `recover` each report `<main>` 0 and
`<h1>` 0. `schedule`/`results`/`me`/`leaderboard` all have both. index.html is the sharp
case — #53 **rebuilt that page from scratch** and it still ships zero landmarks and zero
headings. `timer.html` additionally has **0** `aria-live`/`role="timer"` (confirmed again)
plus **4 unlabeled inputs** and 1 keyboard-inaccessible `div._pillOpt_`. → feeds **#14**,
detail added below.

## Medium

**C1 · The 15-category taxonomy is forked three ways.**
`exerciseGroups.js:28` `ALL_CATEGORIES` (15, family order) · `Exercicios.jsx:14` `BLOCK_ORDER`
(the same 15, different order, drives `initRegistry`) · `utils/config.js:16`
`APP_CONFIG.blockNames` (16, includes a `'-'` sentinel). CLAUDE.md's rule is "extend
`FAMILY_GROUPS` here, never at a call site" — but adding a category to `FAMILY_GROUPS` today
would **not** create its registry bucket, because `initRegistry` iterates `BLOCK_ORDER`. The
new category would render in Pane 1 and silently hold nothing. → **#98**

**U3 · Exercícios on mobile spends its whole first screen on categories that are empty by
design.** At 390 the flat family list renders all seven WOD-family formats (HIIT · MetCon ·
EMOM · For Time · AMRAP · Estações · Benchmark) at **0 exercises with a 0% TallyBar** —
~330px, the entire first viewport — before Força, the first family with content.
`exerciseGroups.js:4-6` already documents *why* they are empty ("they hold formats, not
movements"). Desktop hides this behind a collapsed accordion (`WOD 0`); mobile's flat list
does not. → **#96** (same session)

**T1 · 57 of the 222 lint problems come from gitignored build artifacts.**
`eslint.config.js:8` is `globalIgnores(['dist'])`, which does not cover `.design-build/` (43
problems) or `.design-build-mockup/` (14) — both gitignored generated bundles from
`design:cards`. Real source debt is **165**, up from #32's recorded 155. Cheap correction to
#32 that also stops the number drifting for a reason that isn't code. → corrects **#32**

**G1 · `index.css` is the largest design-debt file in the repo and no session owns it.**
846 lines · **244 hex lines** · **101 literal `border-radius`** vs only 2 tokenised · 26
decimal `rgb()`. C1–C5 are per-tab passes; the global SPA stylesheet falls between them.
Repo-wide radius now splits **48 circles / 49 tokenised / 225 literal**, and index.css alone
is 45% of the literals. → **#99**

**S1 · Real athlete data is sitting untracked and un-ignored in the working tree.**
`cone/ath.json` (an athletes blob) and `cone/rv2.json` (5 `results_v2` rows carrying
`athlete_id`) are untracked but **not gitignored** — one `git add -A` from being committed to
a public repo. Artefacts of the #94 audit. Also untracked at the repo root: five new
`design-*.html` files (design-b/c/criador/d/hybrid), which WORKFLOW.md explicitly forbids
("the old loose `design-*.html` files are **frozen legacy** — never add new ones"). → **#100**

**T2 · The tab that just shipped has no tests.**
`Exercicios.jsx` (600 lines) gained `diffExercise`, `initRegistry` (string→object migration +
per-category re-sort + a `needsSave` write-back), `coverage` and `sortCat` in `118f786` —
all pure or near-pure, all untested. `exerciseGroups.js` got 15 good tests in the same commit;
the tab's own logic got none. `initRegistry` is the risky one: it **writes to the registry on
load** when it decides a migration is needed. → **#101**

## Verified and rejected — findings that are NOT real

Recorded so the next pass doesn't re-raise them:

- **Undefined design tokens beyond `App.css`.** A naive scan flags `--fc`, `--cc`, `--fs`,
  `--bts`, `--zfs`, `--btp-color`, `--pcol`, `--fam`, `--card-color` as undefined. All nine
  are **set at runtime as inline-style custom properties** (`Exercicios.jsx:293`,
  `Publicador.jsx:119`, `TypePicker.jsx:59`, `rail.jsx:135`, `PrSection.jsx:52`,
  `BlockTypePicker.jsx:57`, …). CLAUDE.md's claim that the only undefined tokens live in dead
  `App.css` **holds**, and `--lb-font` remains the only defined-but-unused token (#73 correct).
- **Theme token parity.** All four theme blocks define **exactly the same 30 tokens**, plus
  the 7-token `:root` geometry block. CLAUDE.md correct.
- **The dual-Supabase-client rule.** Every file under `src/public/**` imports
  `../supabaseClient.js` and nothing else; `src/public/shared/**` and `src/components/ui/**`
  import no client at all, directly or transitively. Holds.
- **`tv_state` push() is patch-only.** Every key sent across `useTimer.js:10`,
  `useGroupRotation.js:91/105/115/150`, `useClassTracking.js:39`, `TvController.jsx:176/188`
  is a real column in `0001_init.sql`. No poisoning key. Holds.
- **Session visibility.** All five session-rendering public pages filter
  `s.public !== false && inBoxScope(s, box)` — `rail.jsx:27`, `Index.jsx:12`,
  `Leaderboard.jsx:34`, `Schedule.jsx:106/200/528`, `Me.jsx:301` + `meHelpers.js:76`,
  `Results.jsx:25`. `tv.html` deliberately does not. Holds.
- **Icon-only buttons without an accessible name.** **Zero** across all eight public pages
  *and* zero across the Exercícios tab's 276 buttons. The #50–#53 and C0/C1/C4 a11y slices
  did land; #14's historical "~32 buttons need aria-label" census is spent. What remains of
  #14 is landmarks, headings, live regions and contrast — not naming.
- **Rounded rectangles on public pages.** Literal non-circle radius in `src/public/**` is
  effectively **zero** (2 in the dev-only `Gallery.jsx`). The rule holds; the 225 literals are
  SPA-side.
- **XSS / secrets.** No `dangerouslySetInnerHTML`, `innerHTML`, `eval` or `new Function` in
  `cone/src/`. Every `innerHTML` hit is a legacy root-level HTML file that is **not in
  `vite.public.config.js`'s 9-page input and therefore never built or deployed**. The
  `SUPABASE_SERVICE_ROLE_KEY` in `.env.development` is the published local-demo key and
  carries no `VITE_` prefix. Clean.
- **CI blocks on a red test.** `deploy.yml` runs `npm test` before `build:all`; a failure
  stops the deploy. (No lint gate — that's #32, still open.)
